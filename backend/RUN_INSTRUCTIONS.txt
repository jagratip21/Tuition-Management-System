COMPLETE SETUP GUIDE
═══════════════════════════════════════════════════════════════════════════════

STEP 1: SETUP POSTGRESQL DATABASE
─────────────────────────────────────────────────────────────────────────────

Option A - Local PostgreSQL:

1. Download from: https://www.postgresql.org/download/
2. Install PostgreSQL
3. Open terminal/command prompt
4. Create database:
   $ createdb uphometuition

Option B - Using Docker (easier):

$ docker run --name uphometuition-db \
  -e POSTGRES_PASSWORD=password \
  -e POSTGRES_DB=uphometuition \
  -p 5432:5432 \
  -d postgres:latest

✓ Database is ready!


STEP 2: UPDATE ENVIRONMENT VARIABLES
─────────────────────────────────────────────────────────────────────────────

File: .env (in project root)

Change this:
DATABASE_URL="postgresql://username:password@localhost:5432/uphometuition"

Replace with your PostgreSQL credentials:
- username = your PostgreSQL username (default: postgres)
- password = your PostgreSQL password
- uphometuition = database name (already created)

Example (if using docker):
DATABASE_URL="postgresql://postgres:password@localhost:5432/uphometuition"

Other settings:
JWT_SECRET="your-secret-key-change-in-production"
PORT=3000


STEP 3: INSTALL DEPENDENCIES
─────────────────────────────────────────────────────────────────────────────

$ npm install

Wait for completion (takes 1-2 minutes)


STEP 4: GENERATE PRISMA CLIENT
─────────────────────────────────────────────────────────────────────────────

$ npx prisma generate

This creates the Prisma client for database access


STEP 5: CREATE DATABASE TABLES
─────────────────────────────────────────────────────────────────────────────

$ npx prisma migrate deploy

This creates all tables based on schema.prisma

If first time setup, you might need:
$ npx prisma migrate dev --name init


STEP 6: START THE SERVER
─────────────────────────────────────────────────────────────────────────────

Production mode:
$ npm start

Development mode (auto-reload when you change files):
$ npm run dev

Expected output:
─────────────────────────────────────────────────────────────────────────────
Server is running on port 3000
API Health: http://localhost:3000/api/health
─────────────────────────────────────────────────────────────────────────────


STEP 7: TEST THE API (Open NEW terminal)
─────────────────────────────────────────────────────────────────────────────

TEST 1 - Check if API is running:
$ curl http://localhost:3000/api/health

Expected: API is responding ✓

TEST 2 - Register Admin Account:
$ curl -X POST http://localhost:3000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email": "admin@example.com",
    "password": "AdminPassword123",
    "name": "My Admin"
  }'

⭐ SAVE THE TOKEN FROM RESPONSE! You'll need it for protected endpoints.

TEST 3 - Get All Tutors (Public - no auth needed):
$ curl http://localhost:3000/api/tutors

TEST 4 - Create a Tutor (requires token):
Replace YOUR_TOKEN_HERE with token from TEST 2

$ curl -X POST http://localhost:3000/api/tutors \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -F "fullName=John Doe" \
  -F "email=john@example.com" \
  -F "phone=9876543210" \
  -F "location=New York" \
  -F "expertise=Mathematics"

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Problem: "Cannot connect to database"
Solution:
1. Check .env has correct DATABASE_URL
2. Verify PostgreSQL is running
3. Try direct connection: psql -U postgres -d uphometuition

Problem: "Relation does not exist"
Solution:
$ npx prisma migrate deploy

Problem: "Cannot find module"
Solution:
$ npm install

Problem: "Port 3000 already in use"
Solution:
$ PORT=3001 npm start

Problem: "EADDRINUSE: address already in use :::3000"
Solution - Kill process on port 3000:

Linux/Mac:
$ kill -9 $(lsof -t -i :3000)

Windows:
$ netstat -ano | findstr :3000
$ taskkill /PID <PID> /F

Problem: Authentication token expired
Solution:
Login again to get new token:
$ curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email": "admin@example.com", "password": "AdminPassword123"}'
