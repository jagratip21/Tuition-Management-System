# Tuition Management System

A modern tuition management web application built using **React**, **Vite**, and **Tailwind CSS**. The project provides an intuitive interface for students and tutors, enabling users to explore services, browse subjects, and interact through a responsive user experience.

> This project is currently under active development. Backend integration with **Node.js**, **Express.js**, and **MongoDB** is in progress.

## ✨ Current Features

- Responsive user interface
- Modern landing page
- Student and Tutor modules
- Subject browsing
- Service pages
- Smooth navigation using React Router
- Clean and reusable component-based architecture

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- React Router DOM
- Framer Motion

## 📂 Project Status

This project is actively being improved. Upcoming features include:

- User Authentication
- Student & Tutor Login
- Backend APIs using Express.js
- MongoDB Database Integration
- JWT Authentication
- Admin Dashboard
- Tutor Request Management

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/jagratip21/Tuition-Management-System.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
